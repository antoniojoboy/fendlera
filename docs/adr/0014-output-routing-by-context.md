# ADR-0014 - Output routing by context

**Status:** Accepted. Widened by 0036

**Date:** 2026-09-07

**Context**
Where she speaks matters as much as what she says.

**Decision**
At home, speakers. In public with headphones in, headphones. With only the watch, a buzz or notification. Never audio aloud in public.

**Consequences**
Originally about claim announcements; 0036 makes it the path for everything she emits.
