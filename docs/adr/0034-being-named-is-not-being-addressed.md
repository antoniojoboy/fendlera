# ADR-0034 - Being named is not being addressed

**Status:** Accepted

**Date:** 2026-09-13

**Context**
"Desirée, look this up" and "I'll tell Desirée next week" both contain the name.

**Decision**
The name match still gates what reaches the model. She then judges whether she was addressed or mentioned. A mention is written down, not acted on. An overheard intention becomes a question she raises, never an instruction.

**Consequences**
Ignoring is not an answer; only resolution closes an item. Unresolved items wait for a morning or evening shift summary.
