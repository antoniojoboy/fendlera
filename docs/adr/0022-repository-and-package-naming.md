# ADR-0022 - Repository and package naming

**Status:** Accepted

**Date:** 2026-09-08

**Context**
An umbrella organisation name was unresolved.

**Decision**
Repositories live under the author's own GitHub account; no umbrella organisation. Packages: `fendlera-node` (per machine), `fendlera-companion` (phone). "Agent" does not appear in package names. The phone app is sideloaded; Play Store publication is cancelled.

**Consequences**
Terminology: a node is any machine; Desirée is the one agent; Fendlera is the harness she runs in.
