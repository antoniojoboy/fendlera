# ADR-0032 - First sighting spoken immediately

**Status:** Accepted

**Date:** 2026-09-13

**Context**
Some things cannot wait for evaluation: an unattended flame, an open door.

**Decision**
The first sighting is spoken straight away. A verbal dismissal quietens it but does not close it; she re-raises it later if still true. The interval is her judgement, not configuration.

**Consequences**
Being told something he already knew is an accepted cost.
