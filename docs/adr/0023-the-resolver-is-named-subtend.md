# ADR-0023 - The resolver is named Subtend

**Status:** Accepted. Confirmed final 28 Sep 2026, with Subcortical

**Date:** 2026-09-08

**Context**
The resolver needed its own name. An 11 Sep review flagged a possible collision and marked the name for replacement.

**Decision**
Subtend. It covers the resolver, node agents, enrolment and the intent contract. The perception process is named Subcortical (0028).

**Consequences**
The 11 Sep "names dead" note is superseded. Accepted costs: the sub- prefix reads as subordinate, a possible misread as a subtitle tool, and mishearing against "suspend".
