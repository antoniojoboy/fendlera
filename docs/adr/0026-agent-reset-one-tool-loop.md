# ADR-0026 - Agent reset: one tool loop

**Status:** Accepted. Screen access revised by 0049 and 0054

**Date:** 2026-09-13

**Context**
A day of patching a router and classifier design.

**Decision**
One tool-calling loop. No question routers or classifiers. Her own prose is never fed back in as evidence. A gated build order where nothing is built until the previous step is confirmed on the target machine.

**Consequences**
Proactive monitoring enters the same loop as a second entry point.
