# ADR-0015 - The resolver is part of Fendlera

**Status:** Superseded by 0016

**Date:** 2026-09-07

**Context**
Stripping the agent from the resolver leaves only a context-aware evdev remapper.

**Decision**
The resolver is part of the same suite, not a separate product; still a separate process.

**Consequences**
Reversed the next day.
