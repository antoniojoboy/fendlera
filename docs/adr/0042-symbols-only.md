# ADR-0042 - Symbols only

**Status:** Accepted

**Date:** 2026-09-13

**Context**
Sticks and motion sensors stream with no natural symbol boundary.

**Decision**
Subtend takes symbols. A device that can only stream is not an input device. The watch is an output surface.

**Consequences**
No analog input class. A discrete action from a streaming device enters as a symbol like anything else.
