# ADR-0006 - Name: Fendlera

**Status:** Accepted

**Date:** 2026-09-06

**Context**
The platform needed a name that cleared every registry.

**Decision**
Fendlera. The sweep was clean on all fourteen TLDs, GitHub, GitLab, every package registry and system package manager. *Fendlera rupicola* is a freely branching shrub growing out of dry rock that keeps its seed capsules long after everything else drops: extensibility, no cloud, persistence.

**Consequences**
Accepted weakness: the `Fend-` prefix is populated in AI security (nearest neighbour fendr.tech). Rejected late: Tavlen and Fendler (homophones of existing AI products), Dichroa, Isochroa, Cupel, QXST.
