# ADR-0054 - Perception is ingress; named tools govern egress

**Status:** Accepted

**Date:** 2026-09-28

**Context**
0026 reached the screen through named tools; 0049 made it ambient. They looked like a conflict.

**Decision**
0001 governs what the agent can do, not what feeds in. Ambient perception is ingress and is allowed; the trust question it raises is provenance, answered by 0045.

**Consequences**
The control room reads every camera and cannot open the doors.
